## Experiment constraints (persisted notes)

- **Sample count matters for evaluation.** Eval is distributional, but
  `TrainConfig.number_of_samples` defaulted to **1**. Any run we intend to
  evaluate must set it `>= 8`, otherwise the per-field spatial statistics are
  meaningless (n=1).
- **Training-step budget is wall-clock bound at 1216².** `batch_size` is capped
  at **2** (OOM above), giving ~144 steps/epoch (288 fields). Reaching 1e5 steps
  would need ~700 epochs, infeasible in 12h. Undertraining can therefore only be
  *partially* mitigated by raising epochs — always watch whether a run completes
  before the 12h wall.
- **Presence:** the user is not present between experiments. Do not ask
  mid-iteration; everything is reviewed once the planned runs are all done.
- **Wall clock, measured:** 100 epochs at 1216²/batch2 ≈ **8h** (~4.8 min/epoch
  training). Sampling (`number_of_samples × 1000 steps`) is a fixed per-run cost
  on top. User wants epochs capped at ~10 per run so multiple experiments fit.
- **Wall-clock headroom:** `lr3e4_ep10_v2` (10 ep + 8 samples) ran
  start-to-`SCRIPT DONE` in **~72 min**. The 8h/100ep figure is dominated by
  training; at 10 epochs there is lots of headroom. Could raise epochs to ~20–30
  and still finish several runs, but the user asked to cap at 10 and explore
  OTHER knobs first.

## Results so far

- **`lr=1e-3` with `batch_size=2` DIVERGES.** In `long_ep100_v2` the per-step
  loss fell to ~0.0014 by epoch 6–8, then jumped to ~1.0 at epoch 9–10 and stayed
  there. Because sampling uses the final-epoch weights, the sampled weights were
  post-divergence → samples saturate to all-ice (`ice_frac=0.999`,
  `frac<0.05=0.000`). **Use `lr <= 2e-4` for stability at this batch size.**
- **POSITIVE (duration is the lever):** `long_ep100_v2` (100 ep, *before* its
  epoch-9 divergence) produced visible ice **clusters** in plausible locations and
  much less Gaussian noise than earlier runs. Confirms training-duration is the
  key lever. Goal: capture that structure gain within ~10 epochs while avoiding
  the `lr=1e-3` divergence.
- **BEST SO FAR — `lr3e4_ep10_v2`** (lr=3e-4, 10 ep, batch2). Stable, no
  divergence.
  - `W(conc) = 0.192`
  - `ice_frac = 0.311` vs real 0.305 (**W = 0.079**)
  - `frac<0.05 = 0.322` vs real 0.674
  - water mean 0.137 vs real 0.252
  - Remaining gap = **spatial structure**: `spectrum_L1 = 0.315`,
    `spatial_std = 0.157` vs real 0.379 (fields too smooth / low-contrast,
    under-bimodal).
  - Value distribution is good; structure needs more effective steps.

## Out-of-bounds findings (to raise)

- **No gradient clipping + always samples final-epoch weights.** The training
  loop (`models/ddpm.py` `DDPM.train`) has no gradient clipping and always samples
  from the FINAL-epoch weights. This makes the `lr=1e-3` divergence
  unrecoverable (per-10-epoch checkpoints exist but are never used for sampling).
  Two pipeline improvements to consider: (1) add gradient clipping
  (e.g. `clip_grad_norm_ ~1.0`), and (2) keep/select a best/EMA checkpoint for
  sampling instead of the last-epoch weights.
